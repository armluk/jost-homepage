# Homepage Jost Landtechnik AG – Testversion

Statische Website (HTML, CSS, JavaScript) der Jost Landtechnik AG, Obermattweg 25, 3550 Langnau i.E.
Kein Build-Schritt nötig: Die Dateien können direkt auf einen Webserver oder GitHub Pages geladen werden.

## Seiten
| Datei | Inhalt |
|---|---|
| `index.html` | Startseite mit Slideshow, Aktuelles, Occasion im Fokus, Leistungen, Vertretungen |
| `arbeiten.html` | Reparatur (mit Werkstatt-Beispielen) und Oldtimer |
| `produkte.html` | Alle Vertretungen mit Link zum Hersteller |
| `dienstleistungen.html` | Dienstleistungen und Werkstattausrüstung |
| `occasionen.html` | Occasionen live von agropool.ch |
| `kontakt.html` | Kontakt, Öffnungszeiten, Karte, Formular |
| `impressum.html`, `datenschutz.html` | Rechtliches (Entwurf) |
| `archiv.html` | Archiv der älteren «Aktuelles»-Beiträge |
| `archiv-werkstatt.html` | Archiv der älteren Werkstatt-Beispiele |

## Aufbau
- `layout.js` – Kopfzeile, Menü, Fusszeile und Icons für alle Seiten
- `style.css` – gesamtes Design
- `occasion-spot.js` – zufällige Occasion von agropool.ch
- `logos/`, `produktbilder/`, `aktuelles-bilder/`, `aktuelles-dokumente/` – Bilder und PDFs

## Hinweise zur Testversion
